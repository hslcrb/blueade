# Changelog

## [0.1.0] - 2026-10-25 (experimental)

- Bluade branding, SVG wordmark and app icon
- Single-window Electron ZIP explorer + creation + extraction + CRC check
- In-window operation center with progress, speed, ETA and cancellation
- Safe ZIP path checks, symlink refusal and no-clobber extraction
- Security documentation, human/agent contribution rules and Windows packaging workflow

Windows desktop binaries are produced only after a successful hosted build. This source tree is an experimental baseline, **not a certified release**.
