# Bluade identity / 블루에이드 브랜드 가이드

> **압축을 맑게. Make every archive feel clear.**

## 이름과 철학

Bluade는 *Blue*의 신뢰감과 *Aid*의 동반자성을 연상시키는 이름입니다. 고유한 조어로서 법률상 상표권 확보나 기존 사용 여부는 별도로 조사해야 합니다. '파일의 무게를 덜되, 선택의 권한은 사용자에게 돌려준다'는 원칙으로 설계합니다.

- **Calm** — 진행 상태가 사용자에게 먼저 말합니다. 불필요한 모달을 쌓지 않습니다.
- **Visible** — 속도, 처리량, 현재 파일, 예상 남은 시간, 결과를 작업 센터에서 확인합니다.
- **Respectful** — 광고 자리임을 명시하고 사용자를 추적하지 않습니다.
- **Safe by default** — 절대 경로, 상위 폴더 탈출, 심볼릭 링크, 덮어쓰기 위험을 방어합니다.
- **Human + Agent** — 사람이 이해하는 한국어, 자동화가 이해하는 스키마와 예측 가능한 상태를 함께 제공합니다.

## 시각 언어

| 토큰 | 값 | 역할 |
| --- | --- | --- |
| `ocean-600` | `#336DE3` | 주요 행동, 상태 강조 |
| `ocean-800` | `#1248B8` | 브랜드 핵심 |
| `sky-300` | `#B8F3FF` | B 리본의 밝은 물결 |
| `ink` | `#182E54` | 주요 텍스트 |
| `canvas` | `#F4F8FF` | 문서/패널 배경 |
| `ad-gradient` | `#A9CAFA → #17366F` | 위는 옅고 아래는 깊은 파랑 |

스퀘어 라운드 아이콘의 **B + 대각선 리본**은 파일이 정리되는 흐름을 시각화합니다. 보조 문구는 **"압축을 맑게, 작업은 가볍게"**.

## 광고 슬롯

광고는 현재 실제 광고 SDK가 아닌 자리표시자이며, 지정된 문구 **"이곳은\n광고입니다"**만 노출합니다. 타사 이미지/광고를 복제하지 않습니다. 광고 도입 시 트래킹/광고표시 규정과 사용자 동의가 필요합니다.

## 폰트 정책

사용자 이미지에는 폰트 ZIP이 보일 뿐 폰트 자체는 제공되지 않았습니다. 폰트 임베딩은 적법한 파일 확보 시 수행합니다. 기본 체계는 운영체제의 가용 한글 폰트입니다.
