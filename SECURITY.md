# Responsible security disclosure

Please do **not** publish exploits or malicious sample archives in public issues. Use GitHub **Security → Advisories → Report a vulnerability** for `hslcrb/blueade` where available, or contact the repository maintainers privately via GitHub profile. Include environment, affected version, sanitized steps, expected/actual impact, and a small reproducible ZIP if safe.

Supported versions: `0.1.x` receives best-effort fixes; builds without signed release verification should be treated as experimental. Security architecture: [docs/SECURITY.md](docs/SECURITY.md).
